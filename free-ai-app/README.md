# Free AI Chat — standalone app site

This folder is deployed as its OWN Vercel project (`free-ai-chat`,
https://free-ai-chat-silk.vercel.app) so Chrome treats it as a separate
installable app. The main Fashion Goals site's manifest scope `/` swallows
`/free-ai` on the shared origin, which is why this separate site exists.

- `index.html` — the Free AI Chat page (generated by
  `~/workspace/free-ai-shell-sync.py` from `../free-ai.html`; never edit by
  hand — edit `free-ai.html` and re-run the sync script).
- `free-ai-manifest.json` — PWA manifest, start_url + scope `/`.
- `free-ai-icon.svg` / `free-ai-icon-192.png` / `free-ai-icon-512.png` — app icons.
- `free-ai-sw.js` — pass-through service worker.

The app has NO server functions of its own: all API calls go to
`https://fashion-website-theta-taupe.vercel.app/api/...` (CORS enabled
there), so no env vars are needed in this project.
